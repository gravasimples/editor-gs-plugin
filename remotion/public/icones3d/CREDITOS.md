# Ícones 3D

Fluent Emoji (c) Microsoft Corporation, MIT. https://github.com/microsoft/fluentui-emoji

- 63 PNGs 3D (256×256, fundo transparente) escolhidos para vídeo de criador e anúncio, copiados sem alteração de `assets/<Nome>/3D/` (mãos no tom padrão) e renomeados pelo apelido em português.
- `LICENSE` é o arquivo original do repositório (MIT); ele vai junto com os arquivos em qualquer cópia.
- `catalogo.json`: apelido → arquivo, nome original no Fluent e palavras faladas que chamam o ícone (grafismo `icone3d`, `editor_video/grafismos.py`).
- Não use o nome ou a marca Microsoft em peças; os ícones são só ilustração.
