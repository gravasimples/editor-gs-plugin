# Fluxo: pesquisa-skills

Pesquisar na internet o que existe de novo para ampliar o que o Editor GS sabe fazer: skills e plugins do Claude Code para edição de vídeo, repositórios (GitHub) de edição automática, presets e estilos de criadores que vendem ou publicam, ferramentas gratuitas de apoio e cursos ou criadores com método de edição que está funcionando (Reels, Shorts, TikTok, anúncios). Nada é instalado nem copiado nesta rodada: o resultado é um catálogo de candidatos para o Raphael decidir na aba Banco de skills.

Passos para o Editor:
1. Leia o pedido: ele traz as URLs que já estão no catálogo (não repita) e o foco da rodada, se houver. Use WebSearch e WebFetch (e `curl` na API pública do GitHub, `https://api.github.com/search/repositories?q=...&sort=updated`) com buscas variadas, em português e inglês: "claude code skill video editing", "SKILL.md video edit", "agentic video editing github", "auto edit reels open source", "preset edição reels criador vende", "caption style pack", "remotion template short-form", "ffmpeg whisper cut silence repo", "MCP video", além do foco pedido. Prefira o que foi atualizado nos últimos 6 meses.
2. Para cada candidato que valer a pena (meta: 8 a 15 por rodada, qualidade acima de quantidade), levante: nome, tipo (`skill-claude` quando é pasta com SKILL.md; `plugin` quando é marketplace do Claude Code; `repo`; `estilo` ou preset de criador; `ferramenta`; `criador`; `curso`), url exata, autor, licença (leia o LICENSE; "paga" ou "sem licença" quando for o caso), preço, resumo em 2 frases, `o_que_aproveitar` (lista curta do que ele faz melhor que nós: legenda, gancho, b-roll, ritmo, grafismo, som, fluxo de aprovação, interface…), `como_reproduzir` (hipótese no nosso vocabulário: estilo JSON em `estilos/`, parâmetro de `montar_remotion`, tipo de grafismo, transição, fluxo em `fluxos/`, ferramenta nova no MCP), `evidencia` (estrelas, downloads, views, número de alunos, data do último commit: só o que a fonte mostra; nunca invente número) e `tags`.
3. Escreva o arquivo JSON no caminho indicado no pedido (`skills_banco/achados/<nome>.json`, dentro da sua pasta de trabalho), no formato `{"por": "Editor (pesquisa)", "itens": [ ... ]}`. O gateway junta no catálogo sozinho.
4. Mensagem final na issue com estas seções: `## Resumo` (quantos achados, por tipo, o que mais chamou atenção em 3 linhas), `## Achados` (uma linha por item: nome, tipo, por que vale, link), `## Sugestões para o Editor GS` (até 5: o que daria para reproduzir primeiro e por quê, com esforço P/M/G), `## Pendências` (o que só o Raphael decide: comprar, instalar, pedir licença, contatar criador).
5. Regras: não instale nada, não crie estilo nem fluxo, não baixe vídeo, não gaste crédito de serviço pago (vidIQ etc.). Não copie texto de venda de terceiros como se fosse análise nossa; referência é estudo. Se a busca não achar nada novo, diga: zero achados é resultado válido.
