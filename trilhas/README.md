# Trilhas do Editor GS

Pasta de música de fundo para `adicionar_trilha` e `montar_locucao(trilha=...)`. **Está vazia de propósito**: o Editor nunca inventa um arquivo. Sem trilha aqui, o vídeo sai só com a voz e isso vai em `## Pendências`.

Como abastecer (Raphael):
- Só música com licença livre para uso comercial (ex.: YouTube Audio Library, Pixabay Music, Uppbeat free com atribuição anotada aqui) ou comprada pela Grava Simples.
- Formatos: `.mp3`, `.m4a`, `.wav`, `.ogg`, `.flac`. Nome curto e descritivo: `calma-piano.mp3`, `energia-lofi.mp3`, `tutorial-suave.mp3`.
- Anotar a origem e a licença de cada arquivo na tabela abaixo (a ferramenta `listar_trilhas` mostra o que existe; o Editor cita a trilha usada no `## Resumo`).
- Trilhas que estiverem no Drive em `Materiais do Editor` também aparecem no `listar_trilhas` depois de Biblioteca → Sincronizar (qualquer caminho com "trilha" no nome).
